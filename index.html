    Pre-flight checklist (read before pasting)
            
      
              
    1. Back up the config (System > Config > Backup).
      2. 
              
    2. Confirm which port you manage through, and do not use it as the parent port.
      3. 
              
    3. Check existing DHCP server IDs: show system dhcp server (this export uses IDs 101 and up, fixed per network).
      4. 
              
    4. Create the RemoteStaff group and users first, and set the real pre-shared key (replace PSK_CHANGE_ME).
      5. 
              
    5. Paste the VLAN interfaces before the policies.
      6. 
              
    6. Every object has a fixed name or ID (policies 1000+), so pasting twice overwrites and never adds copies.
      7. 
              
    7. WAN is port1 when ports available is set (wan1 otherwise): DHCP unless you enter the ISP address under Suggested static routes. Do not manage the firewall through it.
      8. 
              
    8. Admin lock-out check: the paste limits admin login to the Management network (trusted hosts) and turns HTTPS/SSH off on Staff. Be on Management, or add your PC as trusthost2, before pasting.
      9. 
              
    9. Turn on MFA for the admin account: System > Administrators > admin > Two-factor authentication (FortiToken).
      10. 
              
    10. Dual WAN: use the SD-WAN zone in policies, not the single WAN port.
      11. 
              
    11. Have a rollback plan: console or out-of-band access, and a way to restore the backup.
